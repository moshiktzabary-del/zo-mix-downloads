# zo-mix-downloads

Public downloads for ZO-Mix — release binaries only, no source code.

ZO-Mix gives each musician their own monitor mix on a phone or tablet, mirrored live from a DiGiCo console.
It runs on a Mac (menu-bar app); musicians join from their phone's browser.

## Download

- **Latest (macOS, Apple Silicon):**
  https://github.com/moshiktzabary-del/zo-mix-downloads/releases/latest/download/ZO-Mix-macOS-AppleSilicon.zip
- All versions: https://github.com/moshiktzabary-del/zo-mix-downloads/releases

Requires a Mac with Apple Silicon (M1 or later), macOS 13 or later. Signed with Developer ID and notarized by Apple.

## Supported consoles

One app for DiGiCo **Quantum** and **SD** consoles, through External Control
(device type `DiGiCo`, Send `52300` / Rcv `52301`).

- Tested on **Quantum3 Offline** and **SD10 Offline (22.0.2232)**.
- Other Quantum / SD models are expected to work but are not yet verified.
- The beta is **read-only on a real console**: nothing done in ZO-Mix changes it.

## Setup

Each release includes the tester guide (`ZO-Mix-Beta-Tester-Guide.md`, also in the release notes): network,
install, the console's External Control, musicians joining, what to try.
